📋 Calculation Methodology:
This dashboard uses Azure Cost Management API with the following approach:
  • List Price (Pay-As-You-Go): AmortizedCost dataset without Reservation/Savings Plan pricing model filters
  • Actual Cost Paid: ActualCost dataset showing amounts after all discounts applied
  • Total Savings Generated: List Price − Actual Cost (calculates savings from both Reservations and Savings Plans combined)
  • Reservation Savings: Filtered ActualCost for items using Reservation pricing model
  • Savings Plan Savings: Filtered ActualCost for items using Savings Plan pricing model
Based on Microsoft-recommended approach from Azure Cost Management documentation. Reference: Analyze costs with Azure Cost Management
