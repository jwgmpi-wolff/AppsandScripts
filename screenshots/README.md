## How to Add Screenshots

1. Open the dashboard at `http://localhost:8000`
2. Use browser DevTools (F12) or a screenshot tool to capture
3. Save as PNG to this directory with filenames above
4. Commit and push to GitHub

Screenshots will automatically display in the README.md when images are added.
