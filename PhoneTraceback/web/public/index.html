      Assignment is not location

      A country calling code or NANP area code describes where a number range was assigned. It does not establish where a caller, device, SIM, or voice gateway is located.

      Can establish
      Number format, calling code, area code, and assigned numbering country.
      Cannot establish
      Current location, subscriber identity, originating carrier route, or whether caller ID was spoofed.
